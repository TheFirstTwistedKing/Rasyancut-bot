# worldbot — 라시안컷 세계관 디스코드 봇 (A안: 페이지 구조 그대로)

## 명령어
- `/목록` : 세계관 문서 목록
- `/설정 이름` : 문서 읽기 (자동완성, 긴 글은 ◀ ▶ 버튼)
- `/검색 키워드` : 모든 문서에서 키워드 찾기
- `/설정추가 이름` : 입력창에 내용을 쓰면 라시안컷 페이지 아래에 새 문서 생성 (서버 관리 권한 + 통합에 '콘텐츠 삽입' 권한 필요)
- `/캐릭터 이름` : 캐릭터 시트 읽기 (`NOTION_CHARACTER_PAGE_ID` 설정 필요)
- `/새로고침` : 노션 최신 내용 즉시 반영 (서버 관리 권한 필요)

## 준비
1. 디스코드 개발자 포털에서 봇 생성 → 토큰 복사 → OAuth2에서 `bot`, `applications.commands` 범위로 서버에 초대
2. 노션에서 내부 통합(Integration) 생성 → 콘텐츠 읽기 권한 → 토큰 복사
3. 라시안컷 페이지 `···` → 연결 → 만든 통합 추가 (하위 페이지에 같이 적용돼요)
4. `.env.example`을 `.env`로 복사하고 값 채우기
5. 실행
```
pip install -r requirements.txt
python main.py
```

## 주의
- `.env`(토큰)는 절대 공유하거나 깃허브에 올리지 마세요. `.gitignore`에 이미 들어 있어요.
- 노션 내용은 5분마다 갱신돼요. 바로 반영하려면 `/새로고침`.
- 하위 문서의 하위 문서(2단계 이상)는 목록에 `📄 제목`으로만 보여요.
