# worldbot — 라시안컷 세계관 디스코드 봇

노션의 세계관 페이지를 읽어서 디스코드에서 보여주는 봇이에요.

## 명령어
| 명령어 | 설명 |
|---|---|
| `/설정 이름` | 문서 열기. 자동완성, 오타·초성·영문명·별칭 검색, 이미지, 하위·상위 문서 이동 버튼 |
| `/목록` | 문서 전체 구조 (들여쓰기) |
| `/검색 키워드` | 문서 본문과 이름·별칭에서 찾기 |
| `/캐릭터 이름` | 캐릭터 시트 열기 (`NOTION_CHARACTER_PAGE_ID` 설정 필요) |
| `/설정추가 이름` | 입력창에 내용을 쓰면 새 문서를 만들어요 (서버 관리 권한 + 통합에 '콘텐츠 삽입' 권한 필요) |
| `/새로고침` | 노션 최신 내용을 바로 반영 (서버 관리 권한) |
| `/비공개목록` | 비공개로 숨긴 문서 목록 (관리자, 본인에게만 보임) |
| `/알림채널 채널:#채널` | 노션 문서가 새로 생기거나 고쳐지면 알려줄 채널 지정 (서버 관리 권한). 값 없이 쓰면 현재 설정 |
| `/알림해제` | 알림 끄기 (서버 관리 권한) |
| `/홈페이지` | 라시안컷 홈페이지 링크와 `홈페이지 열기` 버튼 (주소는 `HOMEPAGE_URL`로 변경) |

## 문서 화면
- **문서를 열면 그 문서에 쓰인 내용만 나와요.** 하위 페이지는 본문에 있던 자리에 `📄 이름` 한 줄로만 표시되고, 내용은 따로 열어요.
- **이동 버튼**: 글이 길면 `◀ 이전`·`다음 ▶`, 상위 문서가 있으면 `⬆ 상위 문서`, 하위 문서가 있으면 **선택창**(25개까지)이 붙어요. 명령어를 쓴 사람만 누를 수 있고, 마지막으로 누른 뒤 10분이 지나면 비활성화돼요. 다른 사람은 직접 `/설정`을 쓰면 돼요.
- **이름만 보여요**: 목록·제목·검색 결과에 상위 이름은 붙지 않아요. 같은 상위 아래 이름이 겹치면 `개요`, `개요 (2)`로 구분하고, 서로 다른 상위 아래 같은 이름은 화면에 똑같이 보이지만 고른 문서가 정확히 열려요.
- **내용이 없는 문서는 `내용 없음`**으로 표시해요.
- **노션 서식**: 굵게, 기울임, 취소선, 밑줄, 코드, 링크(`http`/`https`만), 제목, 글머리·번호·체크 목록, 인용, 코드 블록, 표(줄 단위), 북마크(`🔗 주소`)를 디스코드 서식으로 바꿔요. 글 속의 `* _ ~ |` 같은 문자는 서식으로 오해되지 않게 처리해요. 글자 색과 크기는 반영되지 않아요.
- **이미지**: 노션의 이미지 블록(업로드·외부 링크)을 그 이미지가 있던 부분의 화면 아래에 보여주고, 설명(캡션)은 이미지 아래에 작게 나와요. 한 화면에 최대 9장이고 더 많으면 이어서 나눠요. 노션에 올린 이미지는 주소가 시간이 지나면 만료돼서, 오래된 주소는 **문서를 열 때 노션에서 새로 받아요**(그래서 이미지가 있는 문서는 열 때 조금 더 걸릴 수 있어요). 동영상·파일·PDF는 표시하지 않아요.
- **자동완성은 디스코드 제한으로 25개까지**예요. 입력이 비어 있으면 상위 문서부터 보여주고, 넘으면 마지막 줄에 `… 외 N개 더 있어요`가 나와요(고르면 전체 구조). 글자를 입력하면 25개 밖의 문서도 찾아져요.
- 하위 페이지를 끝까지(최대 6단계, 한 번에 300개) 읽어 둬서 어느 단계의 문서든 찾을 수 있어요. 라시안컷 대표 페이지는 자기 글과 바로 아래 문서 이름만 보여줘요.
- 예전처럼 하위 페이지 내용까지 한꺼번에 보고 싶으면 `notion_api.py` 위쪽의 `INLINE_SUBPAGES = False`를 `True`로 바꾸세요.
- 노션의 표(데이터베이스) 항목과 외부 임베드는 읽지 않아요.

## 비공개 문서
- 노션에서 **제목에 `🔒` 또는 `[비공개]`**가 들어간 문서는 비공개예요. **그 아래 하위 문서도 자동으로 비공개**예요. 표시는 `.env`의 `PRIVATE_MARKERS`(쉼표로 구분)로 바꿀 수 있어요.
- **관리자(Administrator 권한 또는 서버 주인)만** `/설정`·`/캐릭터`로 열 수 있고 자동완성에도 보여요. 열면 **본인에게만 보이는 메시지**로 나와요.
- 그 밖의 모든 곳에서는 숨겨져요: `/목록`, `/검색`, 하위 문서 선택창, 대표 페이지의 `📄` 목록, "찾지 못했어요"의 비슷한 이름, 자동완성의 `외 N개` 숫자, 변경 알림. **관리자가 공개 문서를 열어도 공개 메시지에는 비공개 문서가 나오지 않아요.**
- 관리자는 `/비공개목록`(본인에게만 보임)으로 무엇이 숨겨져 있는지 확인해요. 공개 문서 아래의 비공개 문서는 `상위 / 이름`으로 표시돼요.
- **알아둘 점**
  - **디스코드에서만 숨겨요.** 노션 자체의 공유 설정이 아니라서, 노션 접근 권한이 있는 사람과 통합 토큰을 가진 사람은 그대로 볼 수 있어요.
  - **표시를 붙이거나 뗀 뒤 최대 5분은 이전 상태로 보일 수 있어요**(노션 내용을 5분 간격으로 읽어 오기 때문). 새로 숨긴 문서가 아직 보이면 바로 `/새로고침`을 쓰세요.
  - 표시를 떼면 그 순간 공개돼요. 알림에도 새 문서로 나가요.

## 검색
`/설정`의 이름 입력, 자동완성, `/검색`이 같은 규칙을 써요.
- **영문명**: `성역의 경계(Sacred Boundary)`는 `sacred`, `boundary`로도 찾아져요. 괄호 앞부분(`성역의 경계`)으로도 찾아져요.
- **별칭**: 문서 안에 `별칭: 성지, Sanctum` 한 줄을 쓰면 그 이름들로도 찾아져요(`,` `/` `·` `;`로 구분, 최대 10개). `이명:`, `별명:`, `Aliases:`도 돼요. 그 줄은 본문에도 그대로 보여요.
- **초성**: `ㅅㅇㅇㄱㄱ` 또는 `ㅅㅇㅇ ㄱㄱ`.
- **띄어쓰기 차이**: `성역의경계`도 찾아요. 본문 검색도 글자 사이 공백 차이를 무시해요.
- **오타**: 맞는 이름이 하나도 없을 때만 비슷한 이름을 보여줘요(`솔리리아` → `솔라리아`). 자동완성과 `/검색`에서는 후보로 보여주고, `/설정`은 마음대로 열지 않고 `혹시 이걸 찾으셨나요?`로 알려줘요.
- **순위**: 이름·별칭이 맞은 문서가 본문에 많이 나온 문서보다 먼저 나와요. `/검색` 결과에는 `제목 일치`, `별칭 일치`, `초성 일치`, `비슷한 이름`, `N회`로 이유가 표시돼요.
- 본문 검색은 서식과 상관없이 동작하고, 이미지 설명(캡션)도 찾아요. 각 문서는 자기 글에서만 찾아서 상위·하위가 중복으로 나오지 않아요.

## 노션 변경 알림
1. 서버 관리 권한이 있는 사람이 `/알림채널 채널:#채널`로 채널을 정해요. 봇이 그 채널에서 메시지와 임베드를 올릴 수 있어야 해요.
2. 봇이 노션을 **10분마다**(`NOTIFY_INTERVAL_MIN`, 3~1440분) 확인해서 **새 문서와 수정된 문서의 이름**을 임베드로 알려줘요(한 번에 15개까지, 넘으면 `외 N개`). 아무도 멘션하지 않아요.
3. **글을 쓰는 도중에는 알리지 않아요.** 같은 내용이 약 2분 이상 유지된 뒤에 알려서, 변경 후 확인 주기 한두 번 뒤에 도착해요. 쓰다가 원래대로 되돌린 변경은 알리지 않아요.
4. 본문 내용을 비교해서 감지해요. 하위 문서가 생기거나 이름이 바뀌는 것은 상위 문서의 수정으로 보지 않고, 이미지 주소가 바뀌는 것도 무시해요.
5. 켜는 순간 이미 있는 문서는 알리지 않아요(한꺼번에 쏟아지지 않게). **비공개 문서는 알리지 않고**, 비공개를 풀면 새 문서로 알려요.
6. 채널 설정과 마지막 상태는 `data/notify.json`에 저장돼요(`DATA_DIR`로 위치 변경). 봇이 꺼진 동안 바뀐 내용은 켜진 뒤 확인 주기 한두 번 안에 알려줘요. **이 파일이 지워지면(호스팅이 `data` 폴더를 유지하지 않는 경우 등) 그때의 상태를 새 기준으로 삼아서, 그 사이의 변경은 알림이 가지 않아요.**
7. 삭제된 문서는 알리지 않아요. 알림은 서버마다 채널을 따로 정하고, 알림을 안 쓰면(채널이 없으면) 노션을 추가로 읽지 않아요.

## 준비
1. 디스코드 개발자 포털에서 봇 생성 → 토큰 복사 → OAuth2에서 `bot`, `applications.commands` 범위로 서버에 초대
2. 노션에서 내부 통합(Integration) 생성 → 콘텐츠 읽기 권한(문서 추가를 쓰려면 삽입 권한도) → 토큰 복사
3. 라시안컷 페이지 `···` → 연결 → 만든 통합 추가 (하위 페이지에 같이 적용돼요)
4. `.env.example`을 `.env`로 복사하고 값 채우기
5. 실행: `pip install -r requirements.txt` 후 `python main.py`

| `.env` 항목 | 설명 |
|---|---|
| `DISCORD_TOKEN`, `NOTION_TOKEN` | 토큰 (절대 공유·업로드 금지) |
| `DISCORD_GUILD_ID` | 명령어를 등록할 서버 ID. 쉼표로 여러 개. 비우면 전체 등록(반영까지 최대 1시간) |
| `NOTION_ROOT_PAGE_ID` | 세계관 대표 페이지 ID |
| `NOTION_CHARACTER_PAGE_ID` | (선택) 캐릭터 시트 상위 페이지 ID |
| `HOMEPAGE_URL` | (선택) `/홈페이지` 주소 |
| `PRIVATE_MARKERS` | (선택) 비공개 표시. 기본 `🔒,[비공개]` |
| `NOTIFY_INTERVAL_MIN` | (선택) 알림 확인 간격(분). 기본 10 |
| `DATA_DIR` | (선택) 알림 설정을 저장할 폴더. 기본 `data` |

## 주의
- `.env`(토큰)는 절대 공유하거나 깃허브에 올리지 마세요. `.gitignore`에 이미 들어 있어요.
- 노션 내용은 5분마다 갱신돼요. 바로 반영하려면 `/새로고침`.
- 시작할 때 콘솔에 `노션 읽기 모듈 버전: …`이 찍혀요. 어떤 버전이 돌고 있는지 거기서 확인하세요.
