# worldbot — 라시안컷 세계관 디스코드 봇 (A안: 페이지 구조 그대로)

## 명령어
- `/목록` : 세계관 문서 목록
- `/설정 이름` : 문서 읽기 (자동완성, 긴 글은 ◀ ▶ 버튼)
- `/검색 키워드` : 모든 문서에서 키워드 찾기
- `/설정추가 이름` : 입력창에 내용을 쓰면 라시안컷 페이지 아래에 새 문서 생성 (서버 관리 권한 + 통합에 '콘텐츠 삽입' 권한 필요)
- `/캐릭터 이름` : 캐릭터 시트 읽기 (`NOTION_CHARACTER_PAGE_ID` 설정 필요)
- `/새로고침` : 노션 최신 내용 즉시 반영 (서버 관리 권한 필요)

## 준비
1. 디스코드 개발자 포털에서 봇 생성 → 토큰 복사 → OAuth2에서 `bot`, `applications.commands` 범위로 서버에 초대
2. 노션에서 내부 통합(Integration) 생성 → 콘텐츠 읽기 권한 → 토큰 복사
3. 라시안컷 페이지 `···` → 연결 → 만든 통합 추가 (하위 페이지에 같이 적용돼요)
4. `.env.example`을 `.env`로 복사하고 값 채우기
5. 실행
```
pip install -r requirements.txt
python main.py
```

## 주의
- `.env`(토큰)는 절대 공유하거나 깃허브에 올리지 마세요. `.gitignore`에 이미 들어 있어요.
- 노션 내용은 5분마다 갱신돼요. 바로 반영하려면 `/새로고침`.
- **하위 페이지는 끝까지 읽어요.** 페이지 안의 페이지(최대 6단계, 한 번에 300개까지)를 따라 내려가고, 위 문서를 열면 그 아래 내용이 본문 순서대로 함께 나와요. 단계는 `📄 제목` → `└ 📄 제목` → `└└ 📄 제목`으로 구분해요.
- **하위 페이지도 따로 열 수 있고, 화면에는 그 문서 이름만 보여요.** 자동완성 목록과 열었을 때의 제목, `/검색` 결과에 상위 이름은 붙지 않아요. 예: `/설정 나스켄티아`
  - 입력한 글자는 문서 **자기 이름**에서만 찾아요. 상위 이름 때문에 걸리는 하위 문서는 나오지 않아요.
  - 상위 이름까지 지정하고 싶으면 `빛과 어둠 / 나스켄티아`처럼 `/`로 이어서 입력하면 그 아래 문서만 좁혀서 보여요.
  - 같은 상위 아래 이름이 겹치면 `개요`, `개요 (2)`로 구분돼요. **서로 다른 상위 아래 같은 이름**은 목록에 똑같이 보이지만, 고른 문서가 정확히 열려요(목록 순서는 `/목록`의 순서와 같아요).
- **내용이 없는 페이지는 `내용 없음`으로 표시해요.** 하위 페이지만 있고 자기 글이 없는 문서는 하위 페이지 내용이 나와요.
- 라시안컷 대표 페이지(루트)는 자기 글과 바로 아래 문서 이름만 보여줘요. 전체 문서가 한 번에 쏟아지는 걸 막기 위해서예요. 전체 구조는 `/목록`에서 들여쓰기로 볼 수 있어요.
- `/검색`은 각 문서 자기 글에서만 찾아서, 상위·하위 문서가 중복으로 나오지 않아요.
- 노션의 표(데이터베이스) 안의 항목과 외부 임베드는 읽지 않아요. 페이지가 많으면 5분마다 갱신할 때 몇 초에서 수십 초가 걸릴 수 있어요.
